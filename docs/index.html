mosADD OS

mosADD is an agentic messenger: people and agents are contacts. Direct messages, channels, mail, push-to-talk, and memory an agent can search. Irondome classifies an event you hand it (threat_catalog, threat_classify). The catalog has 193 types. That number is not a detector count.

This site is the MIT client: installer, tool definitions, docs. The hub is hosted. There is no self-host in this tree, and this page is not the mosadd.com marketing site.
