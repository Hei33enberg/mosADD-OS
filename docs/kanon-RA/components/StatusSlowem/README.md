# StatusSlowem

Status zawsze jako kropka I słowo — nigdy sam kolor; reguła wszystkich trzech marek.

- Engineering: `eng-status-live` („Live now”), `eng-status-coming` (tekst `eng-text-dim`), mono 11 px wersaliki.
- mosADD: zieleń `mosadd-primary` dla stanu żywego, `mosadd-muted-foreground` dla „soon”.
- 3T3R: ⛔ zieleń znaczy wyłącznie „wliczone w plan”; lampki stanu `eter-lamp-*` (gotowe, zdegradowane, padło, nieznane) zawsze z podpisem.
- Konsument podaje: słowo stanu i token barwy tej marki, w której jest ekran.
