# EterPigulka

Główne CTA aplikacji 3T3R: pigułka z gradientem fioletu i poświatą, przyklejona u dołu ekranu w zasięgu kciuka.

- `h-[54px]`, `rounded-full` (`eter-radius-pill`), gradient 135° #7c3aed → #a84cb8, mono 12 px / 700 / wersaliki / tracking 0,18em, biel; poświata `0 10px 28px -9px` z `eter-iridescent-purple` (`src/pages/Przedsionek.tsx:336`).
- Podpis pod spodem: mono 9 px wersaliki, biel 40 % („No card · no account to begin”).
- Tekst z plików języków (`s('cta')`), nie wpisany w komponent.
- Nie: cienia rzucanego, zieleni, kwadratowych narożników (to mosADD), czerwonej pigułki (to Engineering).
