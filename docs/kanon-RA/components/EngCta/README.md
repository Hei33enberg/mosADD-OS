# EngCta

Przycisk Engineering: pełna czerwona pigułka, jedna na widok; drugi przycisk to pigułka z włosu.

- Główny: tło `eng-signal`, napis `eng-signal-foreground` (czerń), Geist Mono 13 px / 500 / wersaliki / tracking 0,18em, wysokość 48 px (`control-h-cta`), padding 0 24 px, `eng-radius-pill` (skill `core/Button.jsx`).
- Drugi (`ghost`): przezroczysty, obrys `eng-line`, napis `eng-text`.
- Uczciwość: dopóki kasa jest zamknięta, etykieta mówi o liście oczekujących, nie o zaliczce (`ReserveCta`). Bez licznika sztuk.
- Nie: kwadratu (mosADD), gradientu (3T3R), drugiego czerwonego przycisku w tym samym widoku.
