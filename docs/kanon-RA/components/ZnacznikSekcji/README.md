# ZnacznikSekcji

Numerowany znacznik sekcji `//NN` — wspólna nawigacja stron trzech marek; numeracja ciągła, bez luk.

- mosADD LP: numer mono 11 px / 600 / tracking 0,18em w `mosadd-primary`, tytuł wersalikami w `mosadd-lp-muted-foreground`, kropkowana szyna 3/9 px (LP-B `.mk`).
- Engineering: numer w DotGothic16 (`eng-dot`) w `eng-signal`, tytuł Geist Mono wersalikami w `eng-text-dim`, szyna = włos `eng-line` (rayray.3t3r.com: `//00 WHAT HE IS`).
- Konsument podaje: numer, tytuł sekcji, kotwicę `id` sekcji. Szyna nawigacji strony czyta `data-s`, nie listę na sztywno.
- Nie: numerów z luką, ikon emoji, znacznika jako dekoracji bez sekcji pod spodem.
