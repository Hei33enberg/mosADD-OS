# Realm

Contributor charter for the MIT client. The long form, including what is not promised, is [REALM.md](../REALM.md) at the repository root. This page is the one GitHub Pages serves.

**The crown holds the DNA. The realm holds the infrastructure.** The founder keeps the vision, the name, and the final word ([GOVERNANCE.md](../GOVERNANCE.md)). Merge rights, credit, and the running client sit with the people and agents who earn them.

Nothing here is equity, a token, or an offer.

## What a pull request can change

The installer, the tool definitions, the adapters, Irondome's engine, the skills, the examples, and these docs. Not the hub. Not metering. Not a self-hosted server, because this tree does not contain one.

Write with the words in [words.md](./words.md). In particular: 193 is a catalog, the hub is 0.3.9 only for the day that was measured, and `@mosadd/mcp` alpha.56 is 85 definitions.

## Ladder

| Level | Title | Bar |
|---|---|---|
| L0 | Citizen | show up. [Discussions](https://github.com/Hei33enberg/mosADD-OS/discussions) or [issues](https://github.com/Hei33enberg/mosADD-OS/issues) |
| L1 | Squire | one substantive merged pull request, or sustained triage |
| L2 | Knight | three or more. A row in [HALL_OF_FAME.md](../HALL_OF_FAME.md) |
| L3 | Baron / Baroness | five or more in one area, over three months, with review judgement. [MAINTAINERS.md](../MAINTAINERS.md) |
| L4 | Herald | named by the Crown |
| L5 | Peer of the Realm | a certified integration or a field deployment |

Substantive means a feature, a hard bug fix, or a deep refactor. The machine copy of the ledger is [community/realm.json](../community/realm.json). An agent climbs the same ladder ([AGENTS.md](../AGENTS.md)).

Security reports go to [SECURITY.md](../SECURITY.md), not to issues.

## Money and contributors

Recognition and rights exist now. Hub credit for a contributor is granted case by case. It is not an open catalogue. Phase 3 in the root charter (any stake, revenue share, token) is intent, not a contract. Read that section before you repeat it.
