## How to be added

- **Security:** report via [SECURITY.md](./SECURITY.md). After the fix ships, we'll ask if you want to be acknowledged.
- **Substantive contribution:** land 3+ PRs that the maintainers consider substantive (features, hard bug fixes, deep refactors). Open an issue tagged `hall-of-fame` requesting acknowledgement.

We don't add people for typo fixes, dep bumps, or trivial cleanups — those are appreciated but not in this file. They're recognised via the GitHub contributor list.
