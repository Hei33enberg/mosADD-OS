## How to be added

- **Security (Warden):** report via [SECURITY.md](./SECURITY.md). After the fix ships, we'll ask if you want to be acknowledged.
- **Substantive contribution (Knight, L2):** land 3+ PRs that the maintainers consider substantive (features, hard bug fixes, deep refactors). Maintainers track merged PRs and update the ledger; you can also open an issue tagged `hall-of-fame` if we're slow.
- **Everything else:** the full ladder — levels, criteria, and rewards — is in [REALM.md](./REALM.md).

We don't add people for typo fixes, dep bumps, or trivial cleanups — those are appreciated but not in this file. They're recognised via the GitHub contributor list.
